# Tanzania Software Development

A national open-source software development community for building,
sharing, reviewing, and maintaining software.

## Areas

- Web applications
- Mobile applications
- Desktop applications
- Backend systems
- Frontend systems
- APIs
- Libraries
- Developer tools
- Automation
- Educational software
- Experimental software
- Documentation
- Collaborative projects

## Philosophy

Projects should favour:

- Open collaboration
- Reproducibility
- Documentation
- Testing
- Maintainability
- Security
- Appropriate licensing
- Code review
